本项目遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与 [语义化版本](https://semver.org/lang/zh-CN/)。
需求目标与验收标准见 [`requirements.md`](./requirements.md)。

## [0.4.1] — 2026-10-03

修复开屏体验，以及「看起来点不了网页」的问题。

### 新增

- **每次启动都先播开屏动画**（FR-12）：不再只在「还没输入过网址」时才显示开屏页。
  现在每次启动都先展示开屏页并播放动画，动画结束后**自动进入上次记忆的网页**；
  关掉「开屏动画」则跳过开屏、直接进入网页。系统开启「减少动态效果」时以静态画面快速跳过。

### 修复

- **网页内点击链接没反应（B站 / 百度等可复现）**：`<webview>` 未启用 `allowpopups` 时，
  Chromium 会在请求到达 Electron 的 `setWindowOpenHandler` **之前**就拦掉弹窗，
  导致 `target="_blank"` / `window.open` 这类链接（B站、百度搜索结果等大量使用）
  点了完全没有反应。现给 `<webview>` 加上 `allowpopups`，并在 `setWindowOpenHandler` 中
  返回 `deny`、延后（`setImmediate`）把地址载入**同一个** webview，不新建系统窗口。
- **「停在开屏页、进不去网页」的观感**：之前只有没有记忆网址时才显示开屏页，
  且开屏页不会自动进入网页；现在开屏结束会按记忆网址自动跳转（见「新增」）。
- **穿透模式的误判**：非普通模式现在会在窗口左上角常驻一个**模式徽标**，
  穿透时明确提示「点击已穿透 · 按 Ctrl+Alt+F 切回」，避免误以为程序卡死。
- **穿透提示里的旧快捷键**：提示仍写着已移除的 `Ctrl+Alt+M`，现改为统一的 `Ctrl+Alt+F`。

## [0.4.0] — 2026-10-03

精简快捷键，并把开屏、缩放两处体验补齐。

### 新增

- **统一窗口模式**（FR-4）：把「置顶 / 鼠标穿透 / 悬浮」合并成**一个**循环快捷键
  `Ctrl + Alt + F`：普通 → 悬浮 → 穿透 → 普通。控制面板改为「窗口模式」三个按钮，
  托盘改为子菜单；进入悬浮 / 穿透使用预设不透明度，退回普通时还原。
- **网页缩放**（FR-11）：`Ctrl + =` / `Ctrl + -` 放大缩小，`Ctrl + 0` 复位，
  只影响网页内容。
- **开屏动画开关**（FR-12）：控制面板「开屏动画」或托盘可关闭；关闭后开屏页仍显示，
  但直接呈现静态画面（主进程向起始页注入静态样式，仅对起始页生效）。

### 修复

- **`Ctrl + +` 无法放大网页**：此前缩放依赖 Electron 默认应用菜单的加速键，
  `Ctrl + =`、`Ctrl + +`、小键盘 `+` 都不会触发。现移除应用菜单
  （`Menu.setApplicationMenu(null)`），由程序在 `before-input-event` 里自行处理，
  上述三种按法均可放大。

### 变更

- **精简快捷键**（NFR-3）：移除全局 `Ctrl + Alt + M`（穿透）与 `Ctrl + Alt + T`（置顶），
  窗口内同步移除 `m` / `t`；置顶 / 穿透 / 悬浮统一为 `Ctrl + Alt + F`。
  全局快捷键收窄为 `F` / `H` / `Q` 三个。
- 移除默认应用菜单；`Esc` 在「穿透」模式下退回「悬浮」。

## [0.3.0] — 2026-09-30

聚焦开屏体验，以及「置顶 + 鼠标穿透」下的稳定性。

### 新增

- **极简开屏动画**：默认起始页由「快捷键清单」改为一段安静的动画 ——
  窗口图标逐笔描边、标题渐显、背景柔光缓慢呼吸，只留一条 `Ctrl + L` 提示。
  纯 CSS 实现，无外部资源，并适配 `prefers-reduced-motion`。

### 修复

- **置顶 + 鼠标穿透时，点击其他窗口会导致「丢置顶」**（FR-4 / FR-6）：
  Windows 在本窗口失焦（点击其他窗口、Alt+Tab、其他程序抢焦点）后可能降级 `topmost`，
  使窗口退到后面、快捷键看起来「失灵」。现在只要置顶仍开启，就会在失焦后重新申明置顶，
  窗口稳定浮在最前。
- **关闭鼠标穿透后窗口可能仍压在其他窗口后面**：关闭穿透的同时把窗口抬到最前，
  避免「点了像没反应」。
- **显示窗口时不够可靠**：`Ctrl+Alt+H` / 托盘恢复窗口时重新申明置顶并抬升，
  确保置顶处于开启状态时能立刻看到窗口。

### 变更

- 起始页不再罗列全部快捷键；完整快捷键说明以 [`README.md`](../README.md) 为准。

## [0.2.0] — 2026-09-30

聚焦「全屏、滚动条、快捷键」三类使用体验问题，并首次产出可分发的 exe。

### 新增

- **网页内全屏限制在窗口内**（FR-7）
  - 网页调用 `requestFullscreen()`（如视频播放器）时只让画面铺满本窗口，不再把窗口顶成系统全屏。
  - 采用 `fullscreenable: true` + `disableHtmlFullscreenWindowResize: true`；保留 `fullscreenable` 是因为设成
    `false` 会让 `requestFullscreen()` 直接被浏览器拒绝。
  - 进入网页全屏时自动收起浮层，并把顶部 10px 拖拽条高度归零，避免遮挡播放器自身控件；退出后自动恢复。
  - 以 `enter-html-full-screen` 兜底：万一窗口仍被顶成全屏，立即 `setFullScreen(false)` 还原。
- **隐藏网页滚动条**（FR-8）
  - 通过 `webContents.insertCSS()` 注入样式，只隐藏滚动条外观，滚轮 / 触摸板 / 键盘滚动不受影响。
  - 每次导航后自动重新注入（导航会清除已注入的 CSS）。
  - 外壳自身（控制面板、网址输入条）同步禁用滚动条。
  - 提供开关：`Ctrl+Alt+S` 或托盘菜单「隐藏网页滚动条」。
- **一键关闭快捷键 `Ctrl+Alt+Q`**（FR-9，全局生效）
- **Windows 免安装 exe 打包**（NFR-5）
  - 引入 `electron-builder`，`npm run dist` 产出 portable 单文件 exe。
  - 新增 `build/icon.ico`（由 `build/icon.png` 生成，供 Windows 打包与任务栏使用）。

### 变更

- **移除调整窗口大小的快捷键** `Ctrl+Alt+←/→`：改为纯鼠标操作（拖窗口边缘 / 四角）。
  控制面板中的「－ 缩小 / ＋ 放大」按钮与常用尺寸预设保留。
- 控制面板底部与起始页的快捷键说明同步更新。

### 修复

- 无

## [0.1.0] — 2026-09-30

首个可运行版本。

### 新增

- **无边框窗口**（FR-1）：`frame: false`，只有网页内容，没有标题栏 / 菜单 / 地址栏 / 标签栏。
- **自由调整大小与宽高比**（FR-2）：拖动边缘 / 四角缩放、贴边吸附；`Ctrl+Alt+R` 循环锁定宽高比。
- **透明度调节**（FR-3）：`win.setOpacity()`，10% ~ 100%，步进 10%，数值持久化。
- **一键切换悬浮模式**（FR-4）：`Ctrl+Alt+F` 全局快捷键，置顶 + 预设不透明度，退出时完整还原。
- **隐藏式网址输入条**（FR-5）：`Ctrl+L` 唤出，回车加载、`Esc` 取消。
- **控制面板**：右上角 `⚙` 入口（`Ctrl+Alt+P`），含不透明度滑块、宽高比、尺寸预设、各项开关。
- **鼠标穿透**（FR-6）：`Ctrl+Alt+M` 手动开关，`setIgnoreMouseEvents(true, { forward: true })`。
- **系统托盘**：显示 / 隐藏、悬浮模式、置顶、穿透、滚动条、不透明度预设、宽高比、窗口尺寸、重置、退出。
- **设置持久化**（FR-10）：`%APPDATA%\framelessviewer\settings.json`。
- **默认起始页**：深色页面，列出全部快捷键说明。
- **程序化生成的应用图标**：无第三方依赖，纯 Node 生成 PNG。

### 安全

- 窗口渲染进程启用 `contextIsolation` + `sandbox`，关闭 `nodeIntegration`（NFR-1）。
- 通过 `will-attach-webview` 强制剥离网页 preload 并禁用其 Node 能力。
- 渲染进程仅能访问 `window.frameless` 白名单方法（NFR-2）。

### 修复（发布前自查发现）

- **`Escape` 完全失效**：`if (!mod) return` 写在了 Escape 判断之前，导致无修饰键的 `Esc` 被提前拦截。
- **退出悬浮模式无法还原置顶状态**：进入悬浮模式时 `restore` 被后续的 `setAlwaysOnTop` 覆盖，
  调整赋值顺序后修复。
- **「重新加载」重载的是外壳而非网页**：改为向渲染层发命令重载 `<webview>`。
- **`Ctrl+Alt+H` 只能隐藏不能恢复**：改为切换显隐。

### 变更

- 全局快捷键由 12 个收窄到 4 个。原先把 `Ctrl+Alt+←/→/↑/↓` 注册为系统级快捷键，
  会直接抢占并破坏其他软件的这些组合键；现改为仅在窗口有焦点时生效（NFR-3）。
