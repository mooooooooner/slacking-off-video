FramelessViewer

无边框浏览器已就绪。屏幕上只有网页内容 —— 没有标题栏、没有地址栏、没有标签栏。
需要操作时用下面的快捷键唤出隐藏的控制层。

输入 / 切换网址 Ctrl + L
一键进入 / 退出悬浮模式 Ctrl + Alt + F
调节不透明度 Ctrl + Alt + ↑ / ↓
切换宽高比（自由 / 16:9 …） Ctrl + Alt + R
隐藏 / 显示网页滚动条 Ctrl + Alt + S
鼠标穿透开关 Ctrl + Alt + M
窗口置顶开关 Ctrl + Alt + T
显示 / 隐藏窗口 Ctrl + Alt + H
打开控制面板 Ctrl + Alt + P
一键关闭程序 Ctrl + Alt + Q
隐藏所有浮层 Esc
重置全部设置 Ctrl + Alt + 0

按 Ctrl + L 输入网址开始浏览。
需要调整大小时，直接拖动窗口边缘即可，无需快捷键。
网页里的全屏按钮（例如视频播放器）只会让画面铺满本窗口，不会把窗口顶成系统全屏。
鼠标移到窗口右上角会出现一个 ⚙ 小按钮，点它打开完整控制面板。
